## 포지셔닝

저는 “AI로 여러 데모를 만든 사람”보다, 금융 문제를 데이터·리서치·UX·자동화 시스템으로 구조화하는 빌더에 가깝습니다.

핵심 축은 다음 네 가지입니다.

- 출처 기반 기업분석과 밸류에이션
- PB/WM·금융 리서치 업무 자동화
- 한국 금융 데이터와 MCP 기반 에이전트 인프라
- CUFA 학회 운영, 교육 콘텐츠, Slack 운영 자동화

## 현재 방향

저는 금융권 취업 준비와 창업 실험을 분리하지 않고, 하나의 빌드 로그로 연결하고 있습니다.

1. NEXUS: 금융 데이터와 에이전트 인프라
2. FUND Stack: 현장조사, 밸류에이션, 투자 내러티브, 리스크 규율
3. CUFA Research Ops: 학회 기반 반복 가능한 투자 리서치 운영체계
4. Slack/대시보드 자동화: 실제 커뮤니티 운영에서 쓰이는 자동화

목표는 단순한 결과물이 아니라, 판단을 반복 가능하고 검증 가능한 시스템으로 바꾸는 것입니다.
